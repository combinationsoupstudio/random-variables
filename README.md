# Random Variables

A small, beautiful, low-poly multiplayer sim about scarcity. Ten people turn up to an
office with five computers. Two of them have a problem. What they do about it is the game.

Built solo, start to finish, in public, as a Steam release. Engine: Godot 4 (GDScript).
Design doc: [docs/GDD.md](docs/GDD.md). Decisions: [docs/adr/](docs/adr/). Process: [CLAUDE.md](CLAUDE.md).

## Run it
1. Open the folder in Godot 4.5+ (Project > Import > `project.godot`) and press F5.
2. Or in VS Code: open this folder, F1 > "Godot Tools: Open workspace with Godot editor".
